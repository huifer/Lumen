## 1. 这是个什么东西

一句话：**用一句中文，把你电脑里的图片和文档搜出来。**

比如你输入「红色背景的产品截图」，它会把符合描述的图片找出来，附上缩略图、AI 描述、文件路径和相似度分数。

它的两个特点：

| 特点 | 意思 |
| --- | --- |
| **本地运行** | 你的文件不会被上传到任何地方。AI 只收到"理解结果"，不收到你的文件本身（图片会发给 Google 的 Gemini 分析，但只在你配了 Key 并点「构建索引」时发生） |
| **有 Key 没 Key 都能跑** | 配了免费的 Gemini Key → AI 帮你生成高质量中文描述（推荐）；没 Key → 也能搜，只是描述比较"浅"（只靠颜色、尺寸、文字识别） |

它由两个程序组成（都会在你电脑上运行）：

- **后端**（Python）：真正干活的部分——扫描文件、调 AI、建索引、做搜索
- **前端**（网页）：你看到的界面，在浏览器里打开

## 2. 开始前的准备（只做一次）

### 2.1 你需要装两个软件

| 软件 | 作用 | 下载地址 | 版本要求 |
| --- | --- | --- | --- |
| **Python** | 跑后端 | https://www.python.org/downloads/ | 3.10 或更高 |
| **Node.js** | 跑前端网页 | https://nodejs.org/ | 18 或更高（装 LTS 版） |

安装时一直点「下一步」即可。**macOS 用户注意**：装 Python 时勾选 "Add to PATH"（如果有的话）。

### 2.2 检查是否装好了

打开「终端」：

- **macOS**：按 `Command + 空格`，输入 `终端` 或 `Terminal`，回车
- **Windows**：按 `Win` 键，输入 `PowerShell` 或 `cmd`，回车

在终端里分别输入这两条命令（每输一条按一次回车）：

```bash
python3 --version
node --version
```

**应该看到**类似这样的输出（数字不用一模一样）：

```
Python 3.10.20
v24.15.0
```

✅ 两行都有版本号 → 准备完成，进入第 3 步。
❌ 提示 `command not found` → 说明没装好，回到 2.1 重新安装，装完**关掉终端重新打开**再试。

### 2.3 解压项目

把 `lumen-demo.zip` 解压到一个**路径里没有中文和空格**的文件夹，比如：

- macOS：`~/lumen-demo`（就是「用户/你的名字/lumen-demo」）
- Windows：`D:\lumen-demo`

然后在终端里进入这个文件夹（以后每次操作前都要先做这一步）：

```bash
cd ~/lumen-demo
```

> 💡 `cd` 就是"进入某个文件夹"的意思。你解压到了哪里，就 cd 到哪里。
> 💡 不知道解压到哪了？macOS 可以把文件夹直接**拖进终端窗口**，路径会自动出现。

## 3. 拿到 API Key（免费，5 分钟）

> API Key 就是一串"通行证"字符，证明你有权使用 Google 的 Gemini AI。个人使用**免费**。

1. 打开网址：**https://aistudio.google.com/apikey**
2. 用你的 Google 账号登录（没有就注册一个）
3. 点 **「Create API key」**（创建 API 密钥）
4. 会弹出一串字符，比如 `AIzaSy...` 或 `AQ....` 开头，**点旁边的复制按钮复制它**

> ⚠️ 这串字符等于密码，不要发到群里、不要提交到代码仓库。

### 3.1 把 Key 填进项目

**第一步**：在项目里创建配置文件（复制模板）：

```bash
cd backend
cp .env.example .env
```

**第二步**：用记事本打开这个文件：

- macOS：`open -e .env`
- Windows：`notepad .env`

**第三步**：找到这一行，把你的 Key 粘贴到 `=` 后面，保存并关闭：

```ini
GEMINI_API_KEY=粘贴你刚才复制的那串字符
```

**应该看到**（示例，你的 key 不一样）：

```ini
GEMINI_API_KEY=AIzaSyBxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

保存关闭，回到项目根目录：

```bash
cd ..
```

> ⚠️ 常见错误：
> - `=` 两边**不要有空格**
> - 不要加引号
> - 如果你在国内，可能需要开代理才能打开这个网站和调 API（见第 7 节问题 9）

## 4. 启动系统（3 条命令）

### 方式一：一条命令全启动（推荐）

```bash
bash scripts/dev.sh
```

### 方式二：分别启动（两个终端窗口，方便看日志）

**终端 1 —— 启动后端：**

```bash
bash scripts/start-backend.sh
```

**应该看到**（第一次运行会先自动下载依赖，需要几分钟，耐心等待）：

```
→ 后端启动中: http://127.0.0.1:8000  (docs: /docs)
INFO:     Uvicorn running on http://127.0.0.1:8000
```

> 💡 第一次运行会自动创建虚拟环境并安装依赖（相当于自动下载工具包），只需要等。
> 💡 macOS 如果提示 `Permission denied`，先执行：`chmod +x scripts/*.sh` 再重新运行。

**终端 2 —— 启动前端**（点终端顶部"+"号新开一个窗口，同样先 `cd` 到项目目录）：

```bash
bash scripts/start-frontend.sh
```

**应该看到**：

```
→ 前端启动中: http://127.0.0.1:3000
▲ Next.js 15.5.28
- Local: http://localhost:3000
✓ Ready in 2.1s
```

### 4.1 打开界面

浏览器（Chrome/Safari 都行）访问：

**http://127.0.0.1:3000**

**应该看到**：深色背景的页面，标题「Lumen 本地多模态文件检索」，下面有「索引目录」输入框和一个蓝色「搜索」按钮。

**怎么确认 Key 生效了？** 看页面上的一行小字：

- ✅ 显示 `后端 gemini · 已配置 Gemini Key` → 成功，还能看到「生成模型 / 向量模型」两个下拉框
- ⚠️ 显示 `后端 offline · 无 Key（离线模式）` → Key 没读到，回到 3.1 检查（90% 是 .env 没保存或后端没重启）

## 5. 怎么用（建索引和搜索）

> 「索引」可以理解为"目录卡片"：系统先把每个文件看一遍、写一张内容卡片，之后搜索就是翻卡片，所以**搜索前必须先建索引**。

### 第 1 步：构建索引（首次必做）

1. 「索引目录」框里已经自动填好了自带的测试样本路径，**不用改**
2. 「理解后端」选 **Gemini**（已配 Key 的话）
3. 生成模型 / 向量模型保持「自动」即可
4. 点 **「构建索引」** 按钮

**应该看到**：

- 按钮变成「索引中…」
- 大约 30~60 秒后（8 个测试文件），下方状态栏显示：

```
● 后端 gemini · 已配置 Gemini Key | 已索引 8 个文件 | 本次索引 8 个文件 · 47268ms · 理解后端 gemini
```

> 💡 **为什么要等这么久？** 每个文件都要发给 Gemini 看一遍。好消息是：**结果会存下来**，第二次构建同样的文件几乎瞬间完成（页面上会显示「全部命中缓存，0 次模型调用」）。

### 第 2 步：搜索

在搜索框输入一句中文，点「搜索」（或直接按回车）。试试这四个例子（页面上也有快捷按钮）：

| 你输入 | 你应该看到排第一的结果 |
| --- | --- |
| 红色背景的产品截图 | 红色背景产品截图.png |
| 含有发票的文档 | 发票说明.txt |
| 海边日落照片 | 海边日落.png |
| 合同金额 | 合同摘要.docx |

### 第 3 步：看懂结果卡片

每张卡片上有这些信息：

| 元素 | 意思 |
| --- | --- |
| **0.779**（右上角圆圈） | 相似度分数，越接近 1 越匹配 |
| **缩略图 / TXT·MD·DOCX 标签** | 图片显示缩略图；文档显示类型和内容预览 |
| **描述** | AI 写的这张文件"内容卡片" |
| **小标签**（日落/海景/发票…） | AI 打的关键词 |
| **路径 + 大小** | 文件在你电脑上的位置 |
| **打开原文件 ↗** | 新标签页打开原文件 |

### 小技巧

- 搜索框右边的 **Top 6** 是"最多显示几条结果"，可改成 4/8/12
- 搜过的页面可以直接**复制浏览器地址栏分享**给别人，比如
  `http://127.0.0.1:3000/?q=海边日落照片`
- 页面右上角会显示本次搜索耗时（例如 `2079ms · gemini`）

## 6. 搜自己的文件

想让系统搜你自己的文件夹（比如「下载」文件夹）：

1. 把「索引目录」里的路径改成你的文件夹：
   - macOS：`/Users/你的用户名/Downloads`（也可以直接把文件夹**拖进输入框**）
   - Windows：`C:\Users\你的用户名\Downloads`
2. 点「构建索引」，等它完成
3. 正常搜索

### ⚠️ 搜大文件夹前必读

| 注意 | 说明 |
| --- | --- |
| **免费额度有限** | Gemini 免费档每个模型每天只能"看"约 **20 个文件**。如果你的文件夹有 100 张图，今天只能理解 20 张，其余明天再来（或换模型继续）。已理解的文件会记住，不会重复消耗 |
| **别扫系统目录** | 不要填 `/`、`/System`、`C:\Windows` 这类路径，又慢又容易报错。只扫你自己的文件夹 |
| **支持的文件类型** | 图片：png / jpg / jpeg / gif / webp / bmp；文档：txt / md / csv / json / py / html / yaml / docx / pptx / xlsx；pdf 只记录文件名（不读内容） |
| **时间预期** | Gemini 模式每个文件约 5~20 秒；离线模式快得多 |

## 7. 常见问题排查（对症下药）

### ① 页面显示「连不上后端：...」

| 原因 | 解决 |
| --- | --- |
| 后端没启动 | 回到第 4 节，先把终端 1 里的后端跑起来 |
| 后端启动报错了 | 看终端 1 的红色报错信息，对照本节其他条目 |

### ② 命令报 `Permission denied`（macOS）

```bash
chmod +x scripts/*.sh
```
然后重新运行启动脚本。

### ③ 命令报 `command not found: python3` / `node`

软件没装好，或装完没重开终端。重开终端再试；还不行就重装（第 2.1 节）。

### ④ 端口被占用：`address already in use` / `port 8000 in use`

说明之前启动过还没关。关掉旧的（见第 8 节）再启动；或者换个端口启动后端：

```bash
cd backend
.venv/bin/python -m uvicorn lumen.server:app --port 8001
```

然后告诉前端新地址（新开终端）：

```bash
cd frontend
NEXT_PUBLIC_API_BASE=http://127.0.0.1:8001 npm run dev
```

### ⑤ 显示「无 Key（离线模式）」，明明已经填了 Key

按顺序检查：

1. 文件位置对不对？必须是 **`backend/.env`**（不是项目根目录，不是 .env.example）
2. 内容格式对不对？`GEMINI_API_KEY=AIza...`（`=` 两边无空格、无引号）
3. **改完必须重启后端**（Ctrl+C 关掉，重新运行启动脚本）——这是最常见的原因

### ⑥ 状态栏出现「配额已满：gemini-3.6-flash」

免费档每个模型每天约 20 次，用完了。三个选择：

1. **什么都不做**：系统会自动换其他模型继续（状态栏会显示实际用的模型）
2. 在「生成模型」下拉框里手动换个模型（如 `gemini-3.5-flash-lite`）
3. 明天再建索引（配额每天刷新）；**已处理的文件不用重新处理**（有缓存）

### ⑦ 卡片描述末尾有「（Gemini 调用失败，已回退离线理解）」

该文件调用 Gemini 时网络出错了（比如代理断了一下）。**重新点一次「构建索引」**即可——有缓存机制，成功的文件不会重复消耗额度，只补失败的那几个。

### ⑧ 搜索没有结果 / 结果很少

1. 确认已经点过「构建索引」且显示「已索引 N 个文件」中 N > 0
2. 换个说法再搜（比如「发票」→「含有发票的文档」）
3. 想搜的文件类型系统不支持（见第 6 节的文件类型表）

### ⑨ 在国内，打不开 aistudio.google.com 或建索引一直失败

Gemini 是 Google 的服务，需要网络能访问 Google：

1. 开启你的代理软件（比如 Clash）
2. 让**终端**也走代理（在启动后端的那个终端里，先执行）：

   ```bash
   export https_proxy=http://127.0.0.1:7890
   export http_proxy=http://127.0.0.1:7890
   ```

   （`7890` 是 Clash 默认端口，别的软件请换成自己的端口）
   Windows PowerShell 用：`$env:HTTPS_PROXY="http://127.0.0.1:7890"`
3. 再运行启动脚本

### ⑩ 图片搜到了文字内容，但中文文字搜不到

离线模式靠 tesseract 识别图片文字，需要中文语言包：

```bash
brew install tesseract-lang    # macOS（需先装 Homebrew）
```

装完**重新构建索引**。

### ⑪ 想清空重来

```bash
curl -X DELETE http://127.0.0.1:8000/api/index   # 清空索引（理解缓存还在）
rm -rf backend/data                               # 彻底清空（索引+缓存+缩略图）
```

清空后重新「构建索引」即可。

### ⑫ 还是不行？

把**终端里红色的报错信息**完整复制下来提问，报错信息就是答案的线索。

## 8. 怎么关掉

| 情况 | 操作 |
| --- | --- |
| 关前端/后端 | 回到对应的终端窗口，按 `Ctrl + C`（Mac 也是 Ctrl） |
| 关掉所有相关进程 | `pkill -f "uvicorn lumen.server:app"; pkill -f "next dev"` |
| 下次再启动 | 进入项目目录，重复第 4 节即可（第二次启动很快，依赖已装好） |

关掉后浏览器页面会打不开，这是正常的。你的索引和缓存都保存在 `backend/data/`，下次启动还在。

## 9. 术语小词典

| 术语 | 大白话解释 |
| --- | --- |
| **索引（Index）** | 给每个文件写一张"内容卡片"，搜索时翻卡片而不是重新翻文件 |
| **API Key** | 使用 Google AI 的一串"通行证"字符 |
| **Gemini** | Google 的 AI 模型，负责"看懂"图片和文档 |
| **向量（Embedding）** | 把一段文字变成一串数字，数字越接近 = 意思越接近，用来做语义搜索 |
| **相似度分数** | 0~1 之间，表示"这条结果和你的搜索有多匹配" |
| **缓存（Cache）** | 把 AI 的回答存下来，同样的文件不重复问，省时间也省额度 |
| **429 / 配额** | 免费额度用完了的提示代码 |
| **离线模式** | 不联网也能跑的备用模式，靠颜色、尺寸、文字识别来理解文件 |
| **虚拟环境（venv）** | 一个独立的 Python 小房间，这个项目装的包不影响你电脑其他地方 |
